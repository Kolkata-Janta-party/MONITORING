PRIVACY

Operational data is stored in the monitoring backend.

The public dashboard does not contain analytics or advertising trackers. Monitor definitions, check results, incidents, maintenance windows, deployment records, and alert configuration are stored in the project's protected monitoring database.

Health checks are performed server-side by the monitoring worker, so checks continue when nobody has the dashboard open. Target operators may receive normal network information from the monitoring infrastructure.

Operator authentication uses Supabase Auth. Access tokens remain in the operator browser session and are used only to call the protected monitoring API. Database service credentials and worker secrets remain server-side.

Do not monitor private systems unless you are authorized to do so. Do not place passwords, API keys, cookies, or other credentials in monitor URLs.
